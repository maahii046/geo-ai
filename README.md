# 🌍 GEO AI — Intelligent Outdoor Activity Recommendations

**GEO AI** is an AI-powered prototype that compares weather and air-quality conditions across multiple locations and time periods to recommend potentially more suitable times and places for outdoor activities.

The goal is to help users make more informed outdoor plans using forecast data, air-quality indicators, health-related considerations, and an explainable scoring system.

## ✨ Key Features

- 🌦️ **Weather analysis:** Retrieves forecast information for multiple locations.
- 🌫️ **Air-quality analysis:** Uses PM2.5 and US AQI indicators.
- 📍 **Multi-location comparison:** Compares nine Indian cities across morning, afternoon, and evening periods.
- 🧮 **Recommendation scoring:** Ranks candidate locations and times using application-defined rules.
- 🫁 **Health-aware warnings:** Considers user-provided conditions, such as asthma, when displaying air-quality warnings.
- 🗺️ **Geospatial integration:** Includes location geocoding and a prototype for finding nearby outdoor places.
- 🤖 **AI explanation prototype:** Explores generating natural-language explanations for recommendations.

## 🛠️ Technology Stack

- Python
- Google Colab
- Open-Meteo Weather API
- Open-Meteo Air Quality API
- Geopy and OpenStreetMap Nominatim
- OpenStreetMap Overpass API for nearby-place discovery
- Pandas and Requests
- Folium for map visualization
- SmolLM2 as an experimental local language model

## ⚙️ How It Works

1. Collect the activity, preferred time, location scope, and relevant user-provided health considerations.
2. Retrieve weather and air-quality forecast data.
3. Compare multiple cities and time periods.
4. Apply the prototype scoring rules and generate warnings.
5. Rank candidate options and display the recommendation with supporting forecast values.
6. Retrieve additional location context and, where available, nearby outdoor places.

## ⚠️ Limitations

- The scoring system is a prototype, not a clinically validated health or safety assessment.
- A high score does not guarantee that outdoor activity is safe.
- Forecasts can change and may not reflect conditions at the exact activity location.
- Nearby-place discovery depends on third-party services and may time out.
- The language-model component is experimental; recommendation scores are generated by application-defined rules.
- A public live API endpoint and a fine-tuned model have not yet been documented as available.
